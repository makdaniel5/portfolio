# Mák Dániel – Portfólió weboldal

Ez a projekt egy személyes portfólió weboldal, amely bemutatja a munkáimat, projektjeimet, tanulmányaimat és elérhetőségeimet.

## Főbb funkciók

- Reszponzív, modern felület
- Projektbemutató oldalak
- Akadálymentesítési funkciók
- Kontraszt mód
- Képnagyító modal / image viewer
- Videófelirat és transcript támogatás
- React Router alapú többoldalas navigáció

## Technológiák

- React
- Vite
- React Router
- CSS
- React Icons
